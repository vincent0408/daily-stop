Refresh from this page

The Refresh button starts your GitHub workflow. To do that it needs a GitHub token, which is saved only in this browser.

  1. Open new fine-grained token on GitHub.
  2. Under Repository access, choose Only select repositories and pick this repo.
  3. Under Permissions, set Actions to Read and write. Leave everything else off.
  4. Choose an expiry, generate it, and paste it below.

Rather not use a token? Open the workflow on GitHub and press Run workflow there.
